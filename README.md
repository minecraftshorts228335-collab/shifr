# Практика Python: Алгоритмы шифрования

Этот проект содержит реализацию трех классических шифров подстановок на языке Python: **Шифр Цезаря**, **Аффинный шифр** и **Шифр Атбаш**.

## 📌 Особенности реализации

* **Алфавит:** Работает только с латинскими буквами (`A–Z`, `a–z`).
* **Сохранение символов:** Пробелы, цифры, знаки препинания и символы нелатинского алфавита остаются без изменений.
* **Сохранение регистра:** Заглавные буквы остаются заглавными, строчные — строчными.
* **Модульная структура:** Каждый шифр вынесен в отдельный модуль для удобства поддержки и тестирования.
